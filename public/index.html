ESP32 Hardware & Code Configuration

Pinouts, circuit connections, and server connection settings

ESP32 Pinout Connections

Component ESP32 Pin Type Description
DHT11 / DHT22 GPIO 4 Digital (DHT Library) Air Temperature & Relative Humidity
Soil Moisture Sensor GPIO 34 Analog (ADC1) Higher value = Drier soil (Trigger > 3000)
LDR Light Sensor GPIO 35 Analog (ADC1) Ambient Sunlight Intensity
Relay (Water Pump) GPIO 26 Digital Output Active LOW (LOW = Pump ON, HIGH = OFF)

Connecting ESP32 to This Server

In your Arduino sketch, configure the SERVER_URL:

1. Local Wi-Fi Testing (Your PC):
const char* SERVER_URL = "http://:3000";

Note: Use WiFiClient instead of WiFiClientSecure if using local HTTP.

2. Cloud Deployment (Render.com):
const char* SERVER_URL = "https://your-smartagri.onrender.com";

Keep WiFiClientSecure client; client.setInsecure(); as in your code.

MongoDB Atlas Configuration

Connect your cloud database for persistent telemetry storage

How to get your MongoDB Atlas URI:
  1. Go to cloud.mongodb.com and sign in.
  2. Click Connect on your Database Cluster.
  3. Choose Drivers (Node.js).
  4. Copy the connection string (format: mongodb+srv://<username>:<password>@...).
